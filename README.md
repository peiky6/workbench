# 祈·自律工作台（个人版）

> 一款**纯静态单文件 PWA**，为单一用户打造的个人自律与自我提升工作台。
> 线上地址：`https://peiky6.github.io/workbench/`

---

## 一、定位与面向人群

**定位**：把「雅思备考 / 减脂塑形 / AI 知识积累 / 学习计划推进 / 每日阅读 / 资讯输入」整合到一个随身工作台，用"每日打卡 + 数据可视化 + 周期复盘"帮用户把自律变成可追踪的习惯。

**面向人群**（当前为本人定制）：
- IT 软件项目经理，正从软件 PM **转型 AI 项目经理（AI PM）**；
- 有明确的减脂塑形目标（工作日 16+8 轻断食、乐刻周课表训练）；
- 在备考雅思，需要听说读写不偏科的长期训练；
- 想要一个**无广告、数据私有、手机单端随时打开**的轻量工具，而非重度的习惯养成 App。

---

## 二、核心功能模块

工作台共 **6 大模块** + **首页总览**，全部内嵌在单个 `index.html` 中。

### 🏠 首页总览（Dashboard）
- **今日待办清单**：聚合学习计划 / 体重 / 雅思 / 阅读 / 训练，逐项 ✅/⬜ 可点进对应板块。
- **本周复盘**：近 7 天打卡率、体重变化、计划进度、AI 掌握率 + 文字总结。
- **打卡热力图**：近 18 周 GitHub 风格热力图，附连续/最长连续/活跃天数。
- **专注计时器**：首页入口，记录今日专注时长（`state.focusLog`）。
- **目标设定与提示**：目标体重线、距目标差值、雅思目标总分进度。
- **每日激励语**：根据近期数据动态生成。

### 📚 雅思英语（菜单制）
- `IELTS_MENU` 18 项分 3 类（听说读写 10 / 简历 4 / 日常手册 4），**每日点选 1–2 项**打卡。
- 三条铁律内建：**不偏科**（本周听说读写覆盖）、**保底**（至少 1 项）、**断了不补**。
- 阶段提示：按日期在「口语输入期 → 开口期」间切换。
- 24 天均有**参考答案**折叠显示；已完成的任务可「收起」。
- 听写 / 阅读真题为剑桥公开场景 + 原创参考答案（版权安全）。

### ⚖️ 体重管理（运动 · 饮食 · 体重）
- **身体指标录入**：体重 / 体脂率 / BMI / 基础代谢；BMI、基础代谢按"体重+个人信息"**自动计算预填**，可手动覆盖。
- **饮食记录**：早 / 午 / 晚餐槽 + 食物联想下拉（输入即带出食物与热量）；**本地食物库 FOODS 200+ 条**支持模糊搜索（含赛百味等别名）；**独立「🔢 自定义热量」数字框**（避开输入法改写数字）。
- **饮食计划**：工作日（周一~五）一键套用「训练日计划」；**周六、周日为自由饮食，不套用**。
- **运动记录**：`EXERCISES` 含乐刻操课 + 爬坡 / 深蹲 / 平板等，支持搜索添加；含**乐刻周课表训练计划**与腱鞘炎提示。
- **目标体重线** + 距目标提示，历史回顾展示体脂 / BMI / 基础代谢。

### 📰 新闻阅读
- 虎嗅早报 + 资讯聚合；实时抓取失败自动回退精选内容（CORS 代理限制）。

### 🧠 AI 知识（术语卡复习）
- **术语库 v2**：69 词，分 4 大层级（基础概念 17 / 训练技术 30 / 部署技术 12 / 应用技术 10），面向 AI PM 定制，每张含「通俗含义 + 项目应用场景」。
- **每日 5 张快照**：每天 0 点按日期种子分配一批，当天固定不跳动；**优先分配刷得少的卡**，确保 69 词均匀轮到。
- **复习期规则**：每张卡读完点【📖 已学习】记一遍，**刷满 3 遍才解锁【✅ 已掌握】**；点错可【↺ 撤销一次】。
- **首轮成绩存档**：首轮 69 词已学完的成绩永久保留展示，本轮掌握数从 0 重新累积。
- **掌握率分层进度**面板 + **每周六自测**（一键把答对的标记已掌握，受 3 遍门禁约束）。

### 🗓️ 学习计划（8 月 AI 转型）
- `STUDY_PLAN` 24 天 / 4 周，源自个人《AI 行业转型选择 + 学习计划》。
- **顺序解锁**：完成一项才开下一项；按"今天 = 计划日期"匹配展示，逾期/延期有提示。
- 每天压缩为「约 30 分钟」小任务（精简 content + 可交付 output + 最省时 tip），含参考答案，支持弹性跳过。

### 📖 每日阅读
- 书籍 / 微信读书搜索跳转，阅读记录沉淀。

## 四、数据存储与同步

### 本地存储
- **主存储**：浏览器 `localStorage`（单端手机为主），所有写入自动 `save()`。
- **防丢失**：关键写入点补 `ts=Date.now()`，多端合并时按时间戳 **last-write-wins**。

### 云端同步（可选，免费备份）
- **GitHub Gist**（默认最简）：保存后**自动上传**、打开 App **自动下载合并**；按"模块 + 日期"并集合并。
- **Supabase**（更专业 / 私密）：可选。
- **本地口令加密**：上传前可用 AES 加密，只有你知道口令才能解开。
- **安全**：云端同步数据**不包含 Token / 密钥**（`encodeState` 已剔除 `settings`）。

### 离线能力
- **PWA**：`manifest.webmanifest` + `sw.js`（当前缓存名 v8）。
- 导航请求 `cache:'reload'` 强制拉最新页面；部署新版本时 SW 缓存名递增，**强制手机重新拉取**，避免旧缓存。

## 五、技术栈与部署

- **纯前端单页**，内嵌全部 HTML / CSS / JS（无后端、无构建工具、无框架）。
- 固化**冒烟测试** `smoke.cjs`：抽取 `<script>` 跑 `node --check` + 校验关键函数，每次改完回归。
- **部署**：静态文件推送到 GitHub Pages 仓库 `peiky6/workbench`（main 分支），GitHub Pages 自动发布。
- **架构权衡**：保持单文件以规避工程化拆分带来的线上风险；体积增长时优先采用"无构建多文件 `<script src>`"方案而非引入打包链。

## 六、隐私说明
- 数据默认只存在你自己的浏览器与你自己配置的 Gist / Supabase 中，无第三方收集。
- 开启"本地口令加密"后，云端存放的是密文，口令不离开本地。
