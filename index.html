⚙️ 设置

👤 个人信息

🏃 身体数据（用于卡路里计算）

用于估算基础代谢(BMR)与运动消耗，越准越好。不填则使用默认值。

Katch–McArdle 基于去脂体重（LBM），比 Mifflin 更贴合健身人群；选它后请尽量每天填体脂率，没填时会自动退回 Mifflin 估算。

🎯 目标设定

设定目标后，体重图会显示目标线、首页清单与复盘会追踪进度。先留空也可随时回来填。

阅读用「微习惯」思路：目标设很小（如 5 分钟），容易启动、容易坚持；连续打卡解锁成就，完成后记得去微信读书领书币 📖。

🔔 每日打卡提醒

到设定时间若今日还没全打卡，打开本应用时首页顶部会弹出提醒横幅（任何浏览器、任何打开方式都能用）。

📰 新闻源管理（新闻阅读栏目用）

添加你常看的新闻 / 资讯链接，新闻栏目里会展示，点开即读。

☁️ 云端同步

数据可跨设备同步（GitHub Gist）。可选「本地口令加密」，数据上传前先用 AES 加密，只有你知道口令才能解开。

① GitHub 新建一个 Gist（任意文件名，如 workbench.json）
② 生成带 gist 权限的 Personal Access Token
③ 粘贴上方即可——保存后自动上传、打开 App 自动下载合并（也可随时手动点「上传 / 下载」）。

⚠️ 口令丢失将无法解密云端数据，请牢记。加密后云端（GitHub Gist）只存密文，即使链接或仓库泄露也解不开。

🔒 加密已开启，但还没设口令——请在上方「加密口令」填写并保存，否则云端仍是明文。

💾 本地备份

不想用云端？可直接导出 / 导入 JSON 文件做备份。换手机或换网址前，务必先点「导出 JSON」存一份到手机里，随时可导入恢复，告别数据丢失。
