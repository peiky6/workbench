☁️ 云端同步

数据可跨设备同步。支持 GitHub Gist（最简）或 Supabase（更专业/私密）。两者都可选「本地口令加密」，数据上传前先用 AES 加密，只有你知道口令才能解开。

① GitHub 新建一个 Gist（任意文件名，如 workbench.json）
② 生成带 gist 权限的 Personal Access Token
③ 粘贴上方即可——保存后自动上传、打开 App 自动下载合并（也可随时手动点「上传 / 下载」）。

首次使用 4 步（约 2 分钟）：
① 到 supabase.com 免费新建一个项目
② 项目里 → SQL Editor → 粘贴下面 SQL 执行（建表 + 开放匿名读写）
③ 项目 Settings → API 复制 URL 与 anon key，填到上方
④ 回来点「⬆️ 上传本机」即完成首次同步 ✅

建表 SQL：
create table workbench_sync(id text primary key, data text, updated_at timestamptz default now());
alter table workbench_sync enable row level security;
create policy "pub" on workbench_sync for all using (true) with check (true);
这样本机用 anon key 就能读写这一行（id 固定为 me，数据按你设置的口令加密）。

⚠️ 口令丢失将无法解密云端数据，请牢记。

💾 本地备份

不想用云端？可直接导出 / 导入 JSON 文件做备份。换手机或换网址前，务必先点「导出 JSON」存一份到手机里，随时可导入恢复，告别数据丢失。
